* [Account-Monitor Endpoints](account-monitor-endpoints.md) - Seven monitor endpoints: six ad-platform ones, one per ad platform (four ported from the LFX One BFF's rule engines and read live, Microsoft Ads and X served from saved asynchronous reports because their metrics cannot be read inside one request), of which Google Ads, Meta, Reddit and X return only the campaigns this service recorded for the project because their ad account is shared across foundations while LinkedIn and Microsoft stay account-scoped, and a project-scoped HubSpot email monitor that reads only the marketing emails this service recorded for the project.
* [Microsoft Keyword Insights](microsoft-keyword-insights.md) - The Microsoft Advertising keyword and age/gender audience reads behind the Optimize tab: Google's keyword row shape and (age group, gender) buckets with no device dimension, both scoped to the project's own campaigns on its own connection and served from saved asynchronous reports (one store holding two report kinds) with metrics_as_of and metrics_pending.
* [LinkedIn Creative Image Assets](linkedin-creative-assets.md) - How a LinkedIn dispatch uses stored creative assets: linkedInConfig.variants[].imageAssetId names an image of the brief, validated against LinkedIn's single image ad limits before anything is created, then uploaded once per asset through the Images API after the campaign exists, polled until AVAILABLE and used as the dark post's article thumbnail, with the URNs recorded and a failure degrading the campaign as NOT uploaded or UNCONFIRMED.
* [Microsoft Creative Image Assets](microsoft-creative-assets.md) - How a Microsoft Advertising dispatch uses a stored creative asset: microsoftConfig.imageAssetId names one image of the brief, validated against Microsoft's limits before anything is created, then uploaded once with AddMedia and attached to the Search campaign as a campaign-level Image ad extension, with the ids recorded and a failed attach degrading the campaign as NOT attached or UNCONFIRMED.
* [LinkedIn Audience Insights](linkedin-audience-insights.md) - The LinkedIn professional-demographic read behind the Optimize tab: job function, seniority, industry, company size and country buckets keyed by LinkedIn's verbatim URNs, read live from Ad Analytics for the project's own campaigns on its own connection, every counter flagged approximate because LinkedIn approximates and thresholds demographics.
* [Keyword Targeting on Reddit and X](keyword-targeting-reddit-x.md) - The keyword levers for Reddit and X, where a keyword is an entry in the ad group's or line item's targeting rather than a pausable criterion: a live read, a reduce-only removal and a negative-keyword add, with ownership proven before any write, a compare-and-set revision on Reddit's whole-object write, and per-criterion outcomes on X; per-keyword metrics are a separate read-only Reddit read (keyword performance), and none on X.
* [Reddit Audience Insights](audience-insights-reddit.md) - The Reddit sibling of the Meta, X and Microsoft audience reads: gender, country and community buckets from Reddit Ads API v3 report breakdowns (no age — Reddit has no AGE breakdown), scoped to the project's own campaigns on its own connection and bound account, one filtered report per campaign per breakdown, gated by REDDIT_METRICS_ENABLED and failing closed.
* [Reddit Keyword Performance](keyword-performance-reddit.md) - The Reddit keyword performance read: one read-only row per (campaign, keyword) from the Reddit Ads API v3 KEYWORD report breakdown, top 50 by impressions, sharing the audience read's report reader, trust boundary, limits, gate and fail-closed decoding; acting on a keyword stays with the keyword-targeting levers.
* [Meta Ad-Set Monitor and Pause/Resume](meta-ad-sets.md) - Ad-set-level monitor-and-optimize for Meta: a live read of a campaign's ad sets with status, own budget and delivery counters, and a single-ad-set pause/resume guarded by the campaign row's ETag, provenance proven before any write, ACTIVATE limited to the recorded ad set, one unretried write answered APPLIED / ALREADY_IN_STATE or a 503 when unconfirmed, and a deliberate pause of the recorded ad set kept on the campaign row so a campaign resume leaves it paused.
* [Meta Ad Read Under an Ad Set](meta-ads.md) - A read-only live listing of the ads under one Meta ad set of a campaign this service owns, with status, creative and delivery counters: provenance and the ad set's parent campaign and account proven before its ads are read, every ad's parent ids and every raw body checked, the listing capped with a truncated flag and delivery all or nothing; no per-ad writes.
* [GHCR stale image cleanup](ghcr-image-cleanup.md) - How the scheduled and on-demand GitHub Actions workflow removes stale GHCR image versions, tagged and untagged, for the campaign-service container package.
* [Signed Creative-Asset URLs for Reddit](signed-creative-asset-urls.md) - How a Reddit dispatch uses a stored creative asset: the service serves that one asset at a short-lived HMAC-signed public URL minted server-side immediately before the Reddit post request that passes it as media_url, behind an anonymous GET/HEAD route that answers every rejection with one bare 404, off unless a signing key and https base URL are configured.
* [Google Ads Creative Image Assets](google-creative-assets.md) - How a Google Ads dispatch uses stored creative assets: any of the Demand Gen, Performance Max and Display image slots, plus the Demand Gen video logo, each demandGenAdGroups entry's slots (#460), each demandGenAds entry's (#474), each displayAdGroups entry's (#475) and the Search campaign's two searchAssets slots (#477), accepts an imageAssetId object beside a plain URL string, the dispatcher canonicalizes and loads those bytes under the container's shared asset budget before anything upstream exists, and hands them to the platform client as ResolvedImages keyed by the lfx-asset slot entry it rendered, where a pre-resolved image runs the same per-image cap, decode and geometry checks as a downloaded one.
* [X Ads Creative Image Assets](x-creative-assets.md) - Stored creative images on X Ads: an imageAssetId on the X campaign config is uploaded through the X API v2 chunked media upload, added to the ad account Media Library under a SHA-256-derived name that a retry reuses, and attached as media_keys on the authored promoted-only tweet, all before the campaign POST.
* [Google Ads Targeting Lookups](google-ads-targeting-lookups.md) - Four read-only pickers for the Google Ads create form: a geo target constant search (SuggestGeoTargetConstants, by name or postal code, returning the numeric id geoTargets accepts, readable through the LF system credential because it is public reference data), a user-list read (GAQL on user_list, returning the resource name audienceSegments accepts, resolved as a create resolves; it lists every foundation's user lists on the shared customer, so it is gated on global_marketing_ops), a conversion-action read (GAQL on conversion_action, ENABLED only, resolved as a create resolves; it lists every foundation's actions on the shared customer, so the gateway admits only global_marketing_ops, the LF marketing team, not campaign_manager, which also includes foundation executive directors), and an audience read (GAQL on custom_audience, combined_audience, audience, user_interest or custom_interest, one type per call, usable entries only, optional name search, resolved and gated like the conversion-action read).
* [Reddit Custom Audiences](reddit-custom-audiences.md) - Reddit retargeting and suppression: redditConfig.customAudienceIds and excludedCustomAudienceIds sent as the ad group's targeting.custom_audience_ids and excluded_custom_audience_ids on every ad-group attempt, and a picker read of the ad account's custom audiences; both built from Reddit's public v3 OpenAPI document, off unless REDDIT_CUSTOM_AUDIENCES_ENABLED, and reserved to global_marketing_ops because the audiences live on the LF ad account every foundation shares.
* [Reddit Video Posts](reddit-video-posts.md) - Reddit VIDEO posts from stored assets (#549 gap 5): redditConfig.videoAssetId (a stored video/mp4) and thumbnailAssetId (a stored PNG/JPEG) author a VIDEO post whose video and thumbnail Reddit fetches from late-minted signed URLs, the video at a kind=video URL that serves only video/mp4; built from Reddit's public v3 post schema, off unless REDDIT_VIDEO_ENABLED, and the post shape needs a live probe before the flag goes on.
