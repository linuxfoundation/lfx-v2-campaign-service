# 2026-11-14 — #564 X device platform targeting at create

**Update** — `twitterConfig.platforms` (gap 9 of the X Ads gap review, #564) adds `PLATFORM`
criteria (EQ) to the line item an X create makes, after the conversation topics.

- The rules live in `twitter.NormalizePlatforms`: trimmed, lower-cased, 1-32 letters or digits,
  duplicates dropped, at most 10. The list counts toward the 60-criterion per-create cap, and a
  breach or a wrong JSON type is a synchronous 400.
- Every value is checked against `GET targeting_criteria/platforms` before anything is created,
  through `resolveListedValues`, which the conversation topics now share.
- The same default-off `TWITTER_CREATE_TARGETING_ENABLED` flag. Not role-gated.
- Devices, age, gender and placements from gap 9 are not built (age-bucket and gender values are
  unconfirmed; placements change the line item, not its criteria).
