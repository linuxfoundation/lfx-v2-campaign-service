  event page's visitors; a visitors-only draft gets none, and the prompt tells the model to set
  `include_past_editions` false for one.
- Only the warehouse editions of THIS event are added by default (`sameEventEditions`: name minus
  year equal), since `ResolvePastEventNames` matches the name as a substring and also returns other
  events; those are named in a note.

  segment, not the event page.
- `RegistrantsListMatches` compares the edition exactly, only the ends trimmed.

  `StandingFilterIsUnion` no longer reads a missing or null filter as an empty union.

  the field's legacy meaning is an orphaned list, and lfx-self-serve main tells the operator to
  delete it.
