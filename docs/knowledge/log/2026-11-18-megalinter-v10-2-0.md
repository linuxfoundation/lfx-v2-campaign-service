# 2026-11-18 — MegaLinter v10.2.0 for Go 1.27

**Update** — MegaLinter moves from v9.1.0 to v10.2.0, whose Go tooling
handles the repo's Go 1.27 module with `GOTOOLCHAIN: auto`. v10 removed
KICS, so `REPOSITORY_KICS_ARGUMENTS` is gone (Checkov covers it).
zizmor now runs online with `GITHUB_TOKEN`
(`ACTION_ZIZMOR_UNSECURED_ENV_VARIABLES`), and its findings in the
workflows are fixed: `persist-credentials: false` on every checkout,
`cache: false` on the release workflow's setup-go, `${{ }}` expressions
moved out of `run:` scripts into `env:`, the license-header workflow
pinned to lfx-public-workflows v0.2.0, and inline ignores with a reason
for the tag-pinned SLSA generator and the `github-app` false positive.
The release workflow strips only the leading `v` from the tag
(`${GITHUB_REF_NAME#v}`). hadolint DL3066 is fixed with `USER 65532`, the
Chainguard nonroot UID. golangci-lint stays disabled in MegaLinter because
`make lint` runs it in the build workflow.
Under Go 1.27, osv-scanner cannot run govulncheck and matches by version,
so `github.com/klauspost/compress` (indirect, through NATS) moves from
v1.19.1 to v1.20.2 for GO-2026-6865.
