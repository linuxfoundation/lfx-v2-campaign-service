# 2026-11-13 — #599 OpenTelemetry v1.47.0 release train

**Fix** — Dependabot alert #24 (`AttributeValueLengthLimit` bypass in
`go.opentelemetry.io/otel/sdk/log`, fixed in `v1.47.0`). Dependabot PR #599
bumped only the core, `otel/log` and `otel/sdk/log`, leaving the exporters and
contrib modules on the older train; this replaces it with a coherent bump of the
whole OpenTelemetry set.

- Stable API/SDK, OTLP trace and metric exporters, `otel/log`, `otel/sdk/log`:
  `v1.47.0`. OTLP log exporters `otlploggrpc`/`otlploghttp`: `v0.23.0`.
  Prometheus exporter: `v0.69.0`. Contrib `otelhttp`: `v0.72.0`; Jaeger
  propagator: `v1.47.0`. `go mod tidy` raised the transitive minimums those
  modules require (grpc-gateway, prometheus common/procfs/client_model, oauth2,
  genproto api).
- `pkg/utils/otel.go` installs the logger provider with
  `otel.SetLoggerProvider`; `go.opentelemetry.io/otel/log/global` is deprecated
  in `v1.47.0` and failed lint (staticcheck SA1019).
- Semantic conventions stay on `v1.43.0`, still the SDK's default resource
  schema, so `TestNewResource_NoSchemaConflict` holds.
