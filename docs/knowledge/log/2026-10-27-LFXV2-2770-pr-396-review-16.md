# 2026-10-27 — PR #396 sixteenth review: the send-time check reads a master's sources (LFXV2-2770)

**Fix** — Greptile finding at b29d4cc8.

- A composed audience records its MASTER as the send list, so the send-time check compared the
  standing list's children with the master's id and passed even when the standing list covered the
  master's source list, a send that reaches nobody. `audience.StandingCoversSend` (replacing
  `CoveredSendList`) now also reads each send list's filter and refuses when the standing list
  covers any IN_LIST inclusion source of it; NOT_IN_LIST exclusions are not sources. One `GetList`
  per send list, at most `MaxSendListFilterReads` (50), a larger set refused; a failed read
  refuses. Dispatch and the email wizard both use it.
- Tests (mutation-checked): `TestStandingCoversSend`,
  `TestHubSpot_DispatchRefusesAMasterWhoseSourceTheStandingListNowCovers`,
  `TestSetWizardSendList_RefusesAMasterWhoseSourceTheStandingListNowCovers`.
