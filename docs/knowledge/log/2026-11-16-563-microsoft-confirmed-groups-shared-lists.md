# 2026-11-16 — #563 Microsoft levers address confirmed failed ad groups; shared lists need PartialErrors

**Fix** — Two more #613 review findings. The bid and keyword levers now use every distinct further ad group whose `adGroupId` was confirmed (`microsoftConfirmedExtraAdGroupIDs`), including a `failed` group whose ad or keyword step failed after Microsoft confirmed it. Before this, a bid write on a `created_degraded` campaign saved a new campaign bid while that group kept its old one, and keyword actions refused that group's confirmed keywords. Activation still addresses only `created` groups, so it never opens a partly built one. Separately, `AttachCampaignSharedNegativeKeywordLists` now requires `PartialErrors` in a 200 response. `null` or `[]` still means no error, but a body that omits the field (`{}`) marks every list UNCONFIRMED, so the campaign is `created_degraded` instead of every list being recorded APPLIED.
