# 2026-10-05 — LFXV2-2665 bid writer: update-campaign-bid for Microsoft and Reddit

**Creation** — a new Optimize lever, `PATCH /projects/{project_id}/briefs/{brief_id}/campaigns/{campaign_id}/bid`
(`update-campaign-bid`), modelled end to end on the budget lever: `BriefService.UpdateCampaignBid`
(`internal/service/brief_bid.go`), `Orchestrator.WriteCampaignBid`, the optional `BidWriter`
capability and the sentinels `ErrBidUnsupported` (400), `ErrBidUnwritable` (409) and
`ErrBidAmountRejected` (400), with UNCONFIRMED → 503 "verify the bid in the platform before
retrying".

- **Contract**: one MANUAL max CPC bid (`bid`, account currency, one micro to 1,000,000) plus an
  optional `bid_type` (`cpc` only, default). Never a bid strategy.
- **Microsoft** (`internal/dispatch/microsoft_bid.go`, `internal/platform/microsoft/bid.go`): the
  default `CpcBid` of the ad group the create path recorded, written with `PUT AdGroups` only
  after `GetCampaignsByIds` shows the campaign's own `EnhancedCpc` or `ManualCpc`. Automated
  schemes, portfolios and an unreported scheme → 409. The campaign read is now shared with the
  budget read (`queryCampaignByID`).
- **Reddit** (`internal/dispatch/reddit_bid.go`, `internal/platform/reddit/bid_update.go`): the
  `bid_value` of the recorded ad group, only when it is `MANUAL_BIDDING` + `CPC`. Every campaign
  this service creates is `BIDLESS`, so this leg refuses them until an operator switches the ad
  group to manual bidding.
- **Persistence**: migration `000038_campaigns_max_cpc_bid_column` (expand-only, nullable
  `NUMERIC(18,6)`), written by `ReplaceCampaign` and never by the dispatch upsert.
- Google Ads, LinkedIn, Meta and X answer 400; Meta and X follow in a later PR on the same
  capability.
