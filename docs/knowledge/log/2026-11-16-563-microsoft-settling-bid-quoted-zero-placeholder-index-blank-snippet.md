# 2026-11-16 — #563 Microsoft quoted-zero codes, placeholder indices, blank snippet values

**Fix** — Three #613 review findings. First, `isDefaultCode` treats a quoted `"0"` as a default, matching `isZeroCodePlaceholder`'s documentation, so `{"Index":0,"Code":"0"}` is a placeholder in keyword mutations and shared-list associations. Second, a zero-code placeholder clears only the slot it names. In `attribute`, one with no index or an out-of-range index (or any entry naming an out-of-range index) makes the answer unattributable, so shared-list associations without their own error are UNCONFIRMED. `keywordMutation` also treats such a placeholder-only answer as UNCONFIRMED as a whole, so a pause is not reported APPLIED and the remove is not sent. Third, `reportExistingSnippets` treats a null or blank entry in an existing snippet's `Values` for the requested header as UNCONFIRMED, not definitely NOT attached. Visible values that already cover the request still count as present.
