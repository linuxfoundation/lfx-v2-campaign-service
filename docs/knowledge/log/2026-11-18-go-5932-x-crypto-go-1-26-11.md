# 2026-11-18 — GO-2026-5932 x/crypto v0.59.0 and Go 1.26.11

**Fix** — `golang.org/x/crypto` moves from v0.57.0 to v0.59.0, the first
tagged release without the openpgp packages that GO-2026-5932 flags.
`go mod tidy` pulls the `golang.org/x` modules it requires: x/net v0.62.0,
x/sys v0.50.0, x/text v0.44.0, x/sync v0.25.0, x/term v0.48.0, x/mod
v0.42.0, x/tools v0.52.0 and x/telemetry. The `go` directive moves from
1.26.0 to 1.26.11 so releases, which `ko-build-tag.yaml` builds with
`go-version-file: go.mod`, pick up the crypto/x509 eMudhra CA distrust
added in go1.26.10. The Makefile's unused `GO_VERSION` pin is left as is
(known drift, `known-false-positives.md` § 9).
