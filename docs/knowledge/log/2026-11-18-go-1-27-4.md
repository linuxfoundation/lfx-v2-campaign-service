# 2026-11-18 — Go 1.27.4 and golangci-lint v2.15.0

**Update** — The `go` directive moves from 1.26.11 to 1.27.4, and the
Makefile's `GO_VERSION` follows it. Go 1.27.4 carries the crypto/x509
eMudhra CA distrust that shipped in go1.27.3. `GOLANGCI_LINT_VERSION` moves
from v2.2.2 to v2.15.0, the first release that lints Go 1.27 modules. Its
errcheck flags a discarded `chan error` receive, so three test sites now
use the value or carry a scoped `nolint`. Go 1.27's gofmt aligns
multi-line composite literals differently, so three files are reformatted
with no code change. `CLAUDE.md` gains a "Go version" section recording
that the repo targets Go 1.27.x and supersedes the `lfx-megalinter`
skill's latest-minus-one policy.
