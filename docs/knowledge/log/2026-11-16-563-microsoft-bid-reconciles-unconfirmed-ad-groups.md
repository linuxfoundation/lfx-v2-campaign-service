# 2026-11-16 — #563 Microsoft bid write reconciles unconfirmed ad groups by name

**Fix** — A #613 review finding. The bid write's refusal for a later ad group recorded `unconfirmed` with no id could never clear: it read only the persisted flag, and a re-dispatch reuses the `created_degraded` row. `WriteBid` now reconciles first. `reconcileMicrosoftUnaddressedAdGroups` looks each such group up by its recorded `adGroupName` under the campaign (`Client.FindAdGroupByName`, the same lookup the create's find-first uses). If it is found, its id is recorded (`unconfirmed` cleared, status still `failed`) and it is re-bid with the rest. If it is definitely absent (a complete, readable list without it), the flag is cleared and the write proceeds. Only a lookup that cannot establish it keeps the 409. The reconciled result is persisted with the bid through update-campaign-bid's existing `ReplaceCampaign`, which already writes the result column; the `BidWriter` contract now says the adapter may update `campaign.Result`, and the change is dropped on any error.
