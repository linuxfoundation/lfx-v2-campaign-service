# 2026-11-16 — #563 Microsoft device criteria sent together, zero-code placeholders, snippet values

**Fix** — Three more #613 review findings. Microsoft requires Computers, Smartphones and Tablets in the same `DeviceCriterion` add, so any device bid adjustment now sends all three (`bidAdjustmentCriteria`), an unrequested device at 0. Every result is checked and every id recorded, and the step names the requested adjustments plus the devices sent at +0%. `indexedErrorItem.isError` now shares `audienceErrorCode`'s rule: an entry whose codes are all defaults (absent, null, 0 or "") is a placeholder, so `{"Index":0,"Code":0,"ErrorCode":null}` no longer fails a shared negative list association. A reused campaign's existing structured snippet that has the requested header but missing, null or empty `Values` now makes that snippet UNCONFIRMED rather than definitely not attached.
